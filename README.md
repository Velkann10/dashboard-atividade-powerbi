# 📊 Dashboard de Estatísticas Operacionais

## 📌 Sobre o projeto

Dashboard desenvolvido no **Power BI** para análise e acompanhamento de indicadores operacionais da empresa.

O projeto apresenta informações que auxiliam na visualização e interpretação do desempenho operacional, permitindo uma análise mais objetiva dos principais indicadores.

## 📈 Dashboards

### Página 1 — Estatísticas Operacionais

Apresentação dos principais indicadores e informações relacionadas às estatísticas operacionais da empresa.

![Dashboard 1](dashboard%201.png)

### Página 2 — IPK e Relatório de Viagens

Análise do **IPK (Índice de Passageiros por Quilômetro)** da empresa e apresentação de informações relacionadas ao relatório de viagens.

![Dashboard 2](dashboard%202.png)

## 🛠️ Ferramenta utilizada

- **Microsoft Power BI**

## 🎯 Objetivo

Facilitar a análise dos dados operacionais por meio de visualizações interativas e indicadores, contribuindo para o acompanhamento do desempenho e apoio à tomada de decisões.

## 📂 Arquivo do projeto

O arquivo .pbix utilizado para desenvolvimento do dashboard está disponível neste repositório.
